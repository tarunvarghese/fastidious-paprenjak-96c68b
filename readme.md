# Vargiz Website — V1

Static, mobile-first starter site for Vargiz.

## Structure
- `index.html` — homepage
- `courses.html` — academy placeholder
- `about.html` — about page
- `contact.html` — contact page
- `css/style.css` — design system and responsive styles
- `js/main.js` — mobile navigation and year
- `assets/` — images/icons

## Deploy
Push this folder to a GitHub repository and connect the repository to Netlify. No build command is required; publish directory is the repository root.

## Before launch
- Replace placeholder V mark with the approved Vargiz logo.
- Replace visual placeholders with final photography/art direction.
- Confirm contact email.
- Add legal/privacy pages when required.
